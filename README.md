# Next.js

This is a [Next.js](https://nextjs.org/) project bootstrapped with [`create-next-app`](https://github.com/vercel/next.js/tree/canary/packages/create-next-app).

[Configuration](https://codesandbox.io/docs/projects/learn/setting-up/tasks) has been added to optimize it for [CodeSandbox Projects](https://codesandbox.io/p/dashboard).

## AppNetGuard (iOS app)

[`appnetguard/`](./appnetguard/README.md) contains a Flutter iOS app that lets you cut
internet access for individual apps using a Network Extension content filter. See its
README for the supervised-device requirement and build steps.
